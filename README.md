# scholar-meta-tags

SMT 与 [SMV（scholar-meta-visulization）](https://github.com/sairaisaika/scholar-meta-visulization) 共用一份 Scholar Meta Wiki，覆盖论文标签、模型贡献、人工裁决、主题绑定与证据可视化。

**[打开共享 Wiki](https://github.com/sairaisaika/scholar-meta-visulization/blob/main/docs/wiki/Home.md)** · [本地阅读](../scholar-meta-visulization/docs/wiki/Home.md)

当前仓库尚无独立源码、安装包或运行服务；已实现的标签与账本能力在 SMV 的 `scholar-meta` 包中。仓库定位与代码进度见[共享项目状态](https://github.com/sairaisaika/scholar-meta-visulization/blob/main/docs/wiki/Project-status.md)。共享正文只维护一处，避免两份文档发生分歧。
